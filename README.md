# Practice Project: Node.js + Express Backend & React + Vite Frontend

## Structure

- `/backend` — Node.js + Express backend
- `/frontend` — React + Vite frontend

## Getting Started

### Backend
1. Open a terminal in the `backend` folder
2. Run `npm install` to install dependencies
3. Run `npm start` to start the backend server (http://localhost:5000)

### Frontend
1. Open a terminal in the `frontend` folder
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the frontend dev server (http://localhost:5173)

## Features
- Backend: Express server, CORS, JSON middleware, `/api/users` route
- Frontend: Fetches and displays users from backend
